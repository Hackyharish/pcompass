## Detailed Analysis: What Prompt Compass Reuses, Differs From, and Complements

### 1. `severity1/claude-code-prompt-improver` (MIT)
- **What it does well:** Pioneered low-overhead `UserPromptSubmit` hook evaluation in Claude Code (`scripts/engine.py`, `scripts/rules.py`, `nudges/*.json`). Introduced intuitive bypass prefixes (`*` to skip, `/` for slash commands, `#` for memory notes) and fail-open execution (`exit 0` on any rule error).
- **Where it stops:** Locked to Claude Code; relies on the LLM itself to run research subagents (`Explore`) when a prompt is vague; does not index installed MCP servers, rules files, or CLI binaries; does not route to specific installed skills or recommend missing capabilities.
- **How Prompt Compass relates:** Adopts the `*`, `/`, `#` bypass prefix convention (for muscle-memory compatibility) and the fail-open stdlib-only Python hook model. Replaces LLM-driven prompt evaluation with a deterministic, `<300ms` local restructurer + BM25 capability router that works across 6 agents.

### 2. `prompt-forge-claude-code` / `Bin1783/claude-prompt-forge` (`UNVERIFIED` license)
- **What it does well:** Codifies 10 structural prompt patterns (preamble/trailer framing, negative constraints with reasons, numbered steps) into an interactive skill for authoring system prompts.
- **Where it stops:** Designed for humans authoring reusable LLM prompts from scratch—not a router or per-turn agent brief generator. No license file is present in `Bin1783/claude-prompt-forge`, so we treat its code/templates as proprietary/unlicensed and do not reuse any text from it.

### 3. `skill-router` (`hussi9/skill-router`, MIT) & `skill-router-mcp` (`Mane087/skill-router`)
- **What it does well:** Demonstrates with empirical data why prompt routing is critical: with 291 skills installed, listing them costs ~22,600 tokens per session start and models still fail to invoke relevant domain skills on 40% of prompts. Uses a fast (~80ms) lexical matcher over `SKILL.md` metadata plus project-alias boosting.
- **Where it stops:** Coupled to Claude Code hooks and a specific workflow philosophy (`superpowers` hard edit-blocking gates); indexes skills only (ignoring MCP servers, `.cursor/rules`, `CLAUDE.md`, `AGENTS.md`, and CLI tools); invokes external LLM APIs (Gemini Flash-Lite / Haiku) for low-confidence routes by default.
- **How Prompt Compass relates:** Generalizes lexical + project-signal routing across **all four capability kinds (`skill`, `mcp`, `rule`, `cli`)**, keeps the default path **100% deterministic and offline**, and enforces **strict untrusted-description sanitization** so third-party skill descriptions cannot inject instructions into the brief.

### 4. `skill-swarm` (`ancrz`) & Ecosystem Swarm Skills
- **Status:** An exact public GitHub repository under `ancrz/skill-swarm` could not be verified in the public index on 2026-10-20 (marked `UNVERIFIED`), though multiple `swarm` and `swarm-task-breakdown` skills exist across `skills.sh` and [langchain-ai/deepagents](https://mcpservers.org/agent-skills/langchain-ai/swarm) (MIT).
- **How Prompt Compass relates:** Swarm skills handle downstream multi-agent execution. Prompt Compass sits upstream: when a user submits a multi-component task and a swarm skill is installed, Prompt Compass routes to it in the `Use (installed):` section of the brief.

### 5. `agent-discover` (`keshrath/agent-discover` / `io.github.keshrath/agent-discover`, MIT)
- **What it does well:** Published on the Official MCP Registry (`v3.2.2`, MIT) and npm (`agent-discover`), enabling mid-session discovery and consent-gated installation of MCP servers across Claude Code, Codex, Cursor, VS Code, and Copilot CLI.
- **Where it stops:** Focuses on MCP server discovery from inside an MCP host; does not structure vague prompts, inventory local rules/CLI tools/skills, or perform static AST/regex malware & prompt-injection scanning on third-party `SKILL.md` scripts before recommending them.
- **How Prompt Compass relates:** Complements `agent-discover` by unifying local routing with a **security-gated recommender** (`trust.py` + `scan.py` + `installer.py` + `.promptcompass/lock.json` + `pcompass audit`).

### 6. `wicked-garden` (`mikeparcewski/wicked-garden`, MIT)
- **What it does well:** Uses stdlib-only Python hooks to classify work shapes (`triage`, `build`, `migrate`, etc.), includes an atomic staging installer with rollback (`.staging-*` -> `.old-*`), and provides domain discovery (`wicked-garden`).
- **Where it stops:** Ships as a comprehensive opinionated framework requiring `wicked-vault` for evidence-gated completion checks.
- **How Prompt Compass relates:** Shares the *"Don't fight the harness"* and stdlib-only hook engineering discipline, and uses atomic backup/merge semantics in `pcompass setup` and `pcompass install`.

### 7. `npx skills` (`vercel-labs/skills`, MIT) & Official MCP Registry (`modelcontextprotocol/registry`, Apache-2.0)
- **How Prompt Compass reuses them:** Rather than inventing a new skill marketplace or registry, Prompt Compass treats the **Official MCP Registry (`registry.modelcontextprotocol.io`)**, the **Agent Skills ecosystem (`skills.sh` / GitHub `agent-skills` topic)**, and `.agents/skills/` as its upstream discovery registries. All registry queries use **extracted keywords only—never raw user prompts**.
